# Обоснование выбора тарифа Beget VPS

---

## Нагрузка проекта

ANRO TRIP — сайт туристического агентства с умеренным трафиком:
- Статические страницы (SSR Astro генерирует HTML раз)
- 3 API эндпоинта (формы: callback, gift, review)
- Нет БД, нет тяжёлой серверной логики
- Пиковая нагрузка: поиск туров через Nemo/Tourvisor (iframe/виджет — нагрузка на их серверах)

---

## Тариф: минимальный vs оптимальный

### Минимальный (1 ядро / 1–2 ГБ RAM / 15 ГБ SSD)

**Когда хватит:**
- Трафик до ~1 000 посетителей/день
- Нет фоновых задач
- Минимальный Docker overhead

**Риски:**
- OOM (Out of Memory) при пиковых нагрузках
- Медленная первая сборка Docker-образа
- Нет запаса под логи, мониторинг

### Оптимальный (2 ядра / 4 ГБ RAM / 30 ГБ SSD) ✅ Рекомендуется

**Преимущества:**
- Запас под рост трафика
- Быстрее Docker pull + запуск контейнеров
- Место под логи, резервные копии
- Можно добавить мониторинг (Prometheus/Grafana) при необходимости

---

## Итог

Для старта достаточно минимального тарифа. При первых признаках нагрузки (замедление ответов, OOM) — переходить на 2 ядра / 4 ГБ.

Beget позволяет менять тариф без переустановки ОС.
