Краткий справочник: где на сайте показывается журнал, как устроены файлы, как публиковать статьи вручную и как импортировать посты из MAX в черновики.

## Что такое «Наш блог»

На сайте журнал называется **«Журнал о путешествиях»**. В интерфейсе и якорях встречается как **«Наш блог»**.

| Место            | URL / якорь    | Описание                                               |
| ---------------- | -------------- | ------------------------------------------------------ |
| Блок на главной  | `/#journal`    | **4 карточки** — группы статей по датам, слайд обложек |
| Журнал           | `/blog`        | Те же 4 карточки                                       |
| Карточка         | `/blog/{card}` | Несколько статей подряд, прокрутка + якоря             |
| Старый URL поста | `/blog/{slug}` | 301 на `/blog/{card}#{slug}`                           |

Карточки заданы в `src/data/blog-cards.ts`: `september`, `september-start`, `late-august`, `aviation-events`.

**Принцип публикации:** статья = markdown-файл в репозитории + картинки в `src/assets/blog/` + поле `card`. После коммита и деплоя материал появляется внутри своей карточки.

## Frontmatter статьи

Каждый файл `src/content/blog/*.md` начинается с YAML:

| Поле          | Обязательно | Описание                                                                    |
| ------------- | ----------- | --------------------------------------------------------------------------- |
| `title`       | да          | Заголовок                                                                   |
| `description` | да          | Лид / описание (над текстом и в SEO)                                        |
| `pubDate`     | да          | Дата публикации, формат `'2026-03-18'`                                      |
| `heroImage`   | нет         | Hero в статье (16:9), путь к файлу в `assets/blog/`                         |
| `cardImage`   | нет         | Превью карточки (4:3); если нет — берётся hero                              |
| `heroImages`  | нет         | Коллаж из нескольких фото (2–8)                                             |
| `author`      | нет         | По умолчанию «Команда ANRO TRIP»                                            |
| `destination` | нет         | Тег направления («Турция», «Направления» и т.д.)                            |
| `card`        | да (опубл.) | Группа: `september` / `september-start` / `late-august` / `aviation-events` |
| `featured`    | нет         | устар. для сетки; можно оставить для редакционной пометки                   |
| `updatedDate` | нет         | Дата обновления для SEO                                                     |
| `draft`       | нет         | `true` — **не показывается** на сайте                                       |
| `source`      | нет         | `'max'` — импорт из MAX                                                     |
| `sourceId`    | нет         | ID поста в MAX (для дедупликации)                                           |
| `sourceUrl`   | нет         | Ссылка на пост в MAX                                                        |
| `importedAt`  | нет         | Дата импорта                                                                |

**Slug URL** статьи внутри карточки: `/blog/{card}#{имя-файла}`. Старые `/blog/{slug}` редиректятся.

**Пути к картинкам** относительно файла статьи, обычно:

```yaml
heroImage: '../../assets/blog/turkey-getaway-hero.webp'
cardImage: '../../assets/blog/turkey-getaway-card.webp'
```

## Новая статья вручную

1. Подготовить изображения WebP в `src/assets/blog/` (`pnpm optimize:images` — см. ниже).
2. Создать `src/content/blog/my-article-slug.md` с frontmatter и текстом.
3. Локально проверить:
   ```bash
   pnpm dev
   ```
   Открыть `http://localhost:4321/blog/my-article-slug`
4. Перед коммитом:
   ```bash
   pnpm check
   ```
5. Закоммитить `.md` + картинки → деплой (как обычно для сайта).

### Оформление текста в markdown

В теле статьи можно использовать HTML с классами из `global.css`:

| Класс                       | Назначение                         |
| --------------------------- | ---------------------------------- |
| `blog-content-features`     | Блок списка преимуществ с иконками |
| `blog-content-feature-item` | Один пункт                         |
| `blog-content-feature-icon` | Квадрат с иконкой                  |
| `blog-content-callout`      | Врезка / совет                     |
| `blog-content-lead`         | Лид внутри статьи                  |
| `blog-content-cta`          | CTA-блок в конце                   |

Иконки в markdown: `<i class="fa-solid fa-plane"></i>` — при сборке превращаются в SVG (rehype-плагин).

**В `.astro`-страницах** используйте компонент `FaIcon`, не сырой `<i class="fa-solid">`.

## Публикация из черновика (после MAX или правки)

1. Открыть файл в `src/content/blog/_drafts/`.
2. Отредактировать заголовок, описание, текст, `destination`, обложки.
3. Переименовать файл под нормальный slug, например `seychelles-guide.md`.
4. **Перенести** в `src/content/blog/` (не оставлять в `_drafts/`).
5. Убрать черновик:
   - удалить `draft: true`, или
   - поставить `draft: false`
6. При необходимости:
   ```bash
   pnpm optimize:images
   pnpm check
   ```
7. Коммит + деплой.

**Черновики с `draft: true` не попадают** в `/blog`, на главную в «Журнал» и в sitemap.

## Импорт из MAX

Посты канала **ANRO TRIP • ТУРЫ • АВИАБИЛЕТЫ** можно подтягивать в черновики. На сайт они **не публикуются автоматически**.

### Настройка `.env` (локально и на сервере для скрипта)

Скопировать из `.env.example`:

```env
MAX_BOT_TOKEN=...
MAX_CHANNEL_ID=-70975358582854
```

| Переменная       | Откуда                                                  |
| ---------------- | ------------------------------------------------------- |
| `MAX_BOT_TOKEN`  | [dev.max.ru](https://dev.max.ru) → Чат-боты → токен     |
| `MAX_CHANNEL_ID` | Числовой ID канала (бот должен быть **админом** канала) |

Токен **не коммитить**. Файл `.env` в `.gitignore`.

### Команды

```bash
# Импорт до 20 новых постов (по умолчанию)
pnpm import:max-blog

# Ограничить число новых постов
pnpm import:max-blog -- --limit 5

# Только показать, что будет создано (без записи файлов)
pnpm import:max-blog -- --dry-run

# Докачать обложки у черновиков без heroImage
pnpm import:max-blog -- --sync-images

# Перекачать обложки у всех MAX-черновиков (если раньше был только share-preview)
pnpm import:max-blog -- --sync-images --force-images
```

**Результат:** файлы `src/content/blog/_drafts/max-{id}.md` с `draft: true`, `source: max`, `sourceId`, `sourceUrl`.

**Повторный запуск** не создаёт дубли (проверка по `sourceId` и существующим файлам).

**Картинки:** скрипт берёт фото из постов MAX — вложения `type: image` (i.oneme.ru), превью видео, `image_url` у share. Файлы сохраняются в `src/assets/blog/max/` (WebP, для oneme — до 1440px).

Подробнее: [max-blog-import-plan.md](./max-blog-import-plan.md).

## Скрипты и команды

| Команда                | Назначение                                                      |
| ---------------------- | --------------------------------------------------------------- |
| `pnpm dev`             | Dev-сервер, просмотр `/blog` и статей                           |
| `pnpm check`           | TypeScript + Astro — **перед коммитом**                         |
| `pnpm build`           | Production-сборка (перед деплоем)                               |
| `pnpm preview`         | Просмотр production-сборки локально                             |
| `pnpm import:max-blog` | Импорт MAX → `_drafts/`                                         |
| `pnpm optimize:images` | Оптимизация WebP/AVIF в `src/assets/` (в т.ч. `blog/`)          |
| `pnpm typograf:blog`   | Пакетная типографика markdown-блога (если скрипт есть локально) |

**Типографика:** при сборке markdown проходит через rehype-typograf (`astro.config.mjs`). Заголовки и описания на страницах дополнительно обрабатываются в `src/lib/typograf.ts`.

**Изображения:** `pnpm build` автоматически запускает `optimize:images` (скрипт `prebuild`).

## Featured и направления

- **`featured: true`** — одна «главная» карточка в блоке «Журнал» на главной и в шапке `/blog`. Не ставить `true` на нескольких статьях одновременно.
- **`destination`** — тег в карточках и фильтрах списка (если заполнен).

## Проверка перед выкладкой

| Проверка             | Как                                          |
| -------------------- | -------------------------------------------- |
| Статья открывается   | `/blog/{slug}` в dev/preview                 |
| Черновик не светится | `/blog` и главная — материала нет            |
| OG / превью          | heroImage задан, после build проверить share |
| Типы                 | `pnpm check` без ошибок                      |
| Картинки             | `pnpm optimize:images` для новых файлов      |

## Деплой

Журнал — часть SSR-сборки Astro. После push в `main` и деплоя (Docker + Caddy на VPS, см. [../deploy/server-vps-stack-plan.md](../deploy/server-vps-stack-plan.md)) новые статьи появляются на **anrotrip.ru**.

Импорт MAX на проде: либо запускать `pnpm import:max-blog` на машине разработчика и коммитить черновики, либо настроить cron/GitHub Action (пока **не реализовано** — см. план MAX).

## Частые вопросы

**Почему пост из MAX не на сайте?**  
Импорт создаёт только черновики. Нужна ручная правка и перенос в `src/content/blog/` без `draft: true`.

**Можно ли публиковать без правки?**  
Технически да (снять draft), но не рекомендуется: посты MAX — короткие новости, блог — SEO-материалы.

**Telegram?**  
Автоимпорт только из **MAX**. Telegram в этом проекте используется для уведомлений о заявках, не для блога.

**Где править вёрстку статьи?**  
Шаблон: `src/pages/blog/[slug].astro`. Стили текста: `src/styles/global.css` (секция `.blog-content`).
