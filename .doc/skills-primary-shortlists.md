# Agent Skills: основные шорт-листы

> Рекомендуемые agent skills для работы с проектом в разных режимах.

---

## Режим: разработка кода (15 скилов)

1. `astro` — Astro framework best practices
2. `tailwindcss-v4` — Tailwind CSS v4 синтаксис
3. `typescript` — TypeScript strict mode
4. `accessibility` — WCAG 2.1, aria, семантика
5. `web-performance` — Core Web Vitals, LCP, CLS, INP
6. `seo-technical` — meta, OG, Schema.org, sitemap
7. `docker` — Dockerfile, compose, GHCR
8. `caddy` — Caddyfile, reverse proxy, security headers
9. `github-actions` — CI/CD workflows
10. `nodemailer` — SMTP, email templates
11. `astro-content-collections` — blog, markdown
12. `pwa` — manifest, service worker, offline
13. `playwright` — E2E тесты
14. `sharp` — оптимизация изображений
15. `zod` — validation schemas
