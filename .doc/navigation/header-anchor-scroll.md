# Якоря меню хедера: отступы и scroll-mt

> ⚠️ **НЕ МЕНЯТЬ без согласования с заказчиком.**  
> Числа scroll-mt влияют на то, куда именно скроллит страница при клике на пункт меню.

---

## Проблема: Header перекрывает секцию

Header фиксированный (`fixed top-0`). При скролле к якорю `#section` — секция оказывается под хедером.

**Решение:** Каждая секция имеет `scroll-mt-{n}` равный высоте хедера + нужный зазор.

---

## Механизм плавного скролла

Плавный скролл реализован через единый JavaScript в `Layout.astro` — функция `window.smoothScrollTo(target, offset)`.

- **НЕ используется** CSS `scroll-behavior: smooth` на `html` (тормозит мобайл)
- **НЕ используется** `scroll-snap-type`
- Якорные ссылки в Header перехватываются JS, вычисляется `offsetTop` элемента

---

## Отступ остановки: 20px выше секции

Логика скролла: курсор останавливается **ровно на 20px выше** верхней границы целевой секции. Это единый стандарт для всех якорей.

---

## Мобиль vs Десктоп

- На мобиле высота хедера меньше → scroll-mt может отличаться
- Drawer закрывается **до** начала скролла, чтобы не было смещения
